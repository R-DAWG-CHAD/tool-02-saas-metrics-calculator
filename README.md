# 🚀 SaaS Metrics & Unit Economics Calculator

An interactive, privacy-first dashboard designed for SaaS founders, startup CFOs, and venture investors to evaluate customer lifetime value (LTV), acquisition cost (CAC), payback periods, churn sensitivity, and SaaS Quick Ratios.

## 🚀 Key Features

- **Core Revenue Tracking:** Real-time MRR and ARR computation.
- **Unit Economics Engine:** Evaluates LTV:CAC ratios, CAC Payback Period (Months), and Gross Margin contribution.
- **Retention & Churn Analysis:** Calculates Net Revenue Churn %, logo churn rates, and average customer lifespan in months.
- **SaaS Quick Ratio Evaluator:** Measures net growth velocity by comparing New MRR vs Churned MRR.
- **Interactive Churn Simulator:** Dynamic slider modeling projected 3-year cumulative revenue based on churn reduction.
- **Benchmark Badges:** Instant color-coded rating based on industry standards (VC benchmarks).
- **Dark Glassmorphism UI:** Modern, fully responsive dark-mode interface.
- **Zero External Dependencies:** Built purely with HTML5, CSS3, and native JavaScript.
